# Zyno Voice

Native Android application for **Zyno Voice** (`https://hearth-voice-talk.lovable.app`) with full-screen native experience, voice chat audio permissions, camera & media uploads for posts, and in-app Google sign-in support.

## Direct APK Download

- **Download directly from this repository:** Click [`Zyno-Voice.apk`](./Zyno-Voice.apk) and press **View raw** / **Download**.
- **Or from GitHub Releases / Actions:** Open **Releases** (or **Actions → Build Zyno Voice APK**) to download the latest automated build.
