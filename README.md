# Zyno Voice

Zyno Voice Android application (`https://hearth-voice-talk.lovable.app`) with full-screen native Material 3 styling, SPA back-press navigation, Google Sign-In browser compatibility, runtime permissions management (Microphone, Camera, Notifications, Bluetooth), and media/file uploads.

## Direct APK Download
- **Download directly from this repository:** Click [`Zyno-Voice.apk`](./Zyno-Voice.apk) and press **View raw** / **Download**.
- **Or from GitHub Releases / Actions:** Open **Releases** (or **Actions → Build Zyno Voice APK**) to download the latest automated build.
