# Zyno Voice

Native Android application for **Zyno Voice** (`https://hearth-voice-talk.lovable.app`) with full-screen native experience, voice chat audio permissions, camera & media uploads for posts, and in-app Google sign-in support.

## Direct APK Download from GitHub

1. Push this project to GitHub using AI Studio (**Settings → Push to GitHub**).
2. Wait ~2–3 minutes for the **Build Zyno Voice APK** GitHub Action to complete.
3. Open **Releases** in your GitHub repository (on the right sidebar or at `/releases/latest`) and tap **`Zyno-Voice.apk`** to download and install directly on Android.

Direct release download URL format for your repository:
```text
https://github.com/<YOUR_USERNAME>/<YOUR_REPO>/releases/latest/download/Zyno-Voice.apk
```
